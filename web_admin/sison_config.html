Konfigurasi Koneksi Sison

Atur URL callback dan API Key untuk komunikasi dengan sistem Sison.

API Key ini harus diberikan ke tim IT Sison agar mereka bisa memanggil endpoint kamera.

Dokumentasi Endpoint

Bagikan informasi ini ke tim IT Sison.

POST /api/start

Kirim data transaksi untuk memulai inspeksi kamera.

HEADER WAJIB:
X-Api-Key: [lihat konfigurasi]
REQUEST BODY (JSON):
{ "id_trans": "TRANS-001", "lot": "LOT-2024-001", "p_no": "74231-0K550-00", "unique_no": "UNQ-1234", "p_name": "Nama Part", "qty": 10 }
RESPONSE:
200 OK
{"success": true, "message": "Kamera menerima perintah mulai"}
401 Unauthorized
{"detail": "API Key tidak valid"}

POST Callback Kamera ke Sison

Setelah inspeksi selesai, kamera POST ke URL Sison yang dikonfigurasi.

PAYLOAD YANG DIKIRIM KAMERA:
{ "id_trans": "TRANS-001", "status": 1 } // status: 0=GAGAL | 1=SUKSES | 2=PROSES
